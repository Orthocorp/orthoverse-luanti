Checked 8 Nov 2026 on ContentDB, for the dungeons plan (see [dungeons-plan](dungeons-plan.md)). Not every monster mod that exists, but the main maintained packs. Almost all run on mobs_redo (TenPlus1's mob engine), which the plan already uses; Draconis runs on creatura, which the game already has for animalia.

## Notes for the plan

- Big monsters exist as stand-ins for the great monsters: NSSM's kraken, tarantula, giant sandworm, lava titan and mese dragon; the dragons in Dmobs and Draconis. None has parts that can be cut off, and a reviewer of NSSM found the bigger ones (kraken, tarantula) hard to hit, the box problem noted in the plan.
- Classic adventure monsters by name: orc, skeleton, golem, werewolf, spider, giant ants, manticore, dragons. Goblins, kobolds, ogres and a hydra were not found; they would have to be made or found elsewhere.
- Licences: all are free; MIT, LGPL and CC-BY or CC-BY-SA mix. CC-BY-SA media needs the same licence on changed versions, and every pack needs credit (a credits page on the site would cover it).
- Quality varies: check each monster's look, animations and behaviour in our world before allowing it. A small chosen set suits the game better than everything at once.
